📌 ملخص مطلوب الدرس 19:
Checkpoint: API Mapping into Paginated Table (Pagination)
============================================================

💡 الفكرة الأساسية (The Core Idea):
بدل ما نعرض كل البيانات في الجدول دفعة واحدة (مثلاً 1000 صف)،
نعرض صفحة واحدة فقط في كل مرة مثل صفحات الكتاب، مع أزرار تنقل:
(Previous / أرقام الصفحات / Next) + قائمة لاختيار عدد الصفوف (pageSize).

------------------------------------------------------------
⚙️ خطوات العمل بالترتيب (Pipeline):

1) جلب البيانات (fetch):
- نستخدم async / await مع try / catch لجلب البيانات من الـ API
  وتخزينها في مصفوفة allUsers.
- نعرض حالة التحميل (Loading) وحالة الخطأ (Error) لو فشل الطلب.

2) حسابات الترقيم (The 4 Lines of Math):
نعتمد على 3 متغيرات أساسية:
currentPage (يبدأ من 1) | pageSize | total

  total = allUsers.length
  start = (currentPage - 1) * pageSize
  pageUsers = allUsers.slice(start, start + pageSize)
  totalPages = Math.ceil(total / pageSize)

3) رسم الجدول (render):
- نحوّل عناصر pageUsers إلى صفوف <tr> باستخدام map() ثم join("")
  ونضعها داخل tbody عبر innerHTML.
- نمرّر القيم عبر دالة escapeHtml() للحماية من ثغرات الـ XSS.
- لو المصفوفة فاضية (total === 0) نعرض رسالة Empty State واضحة.

4) رسم الأزرار والتعامل مع النقرات (Event Delegation):
- ننشئ أزرار الصفحات مع خاصية data-page.
- نضع مستمع نقر واحد فقط على الحاوية الأب (#pageNumbers)
  ونلتقط الزر عبر: event.target.closest("[data-page]").

------------------------------------------------------------
🛡️ البرمجة الدفاعية (4 Checks):
المطلوب حماية الجدول من الحالات غير المتوقعة عبر 4 فحوصات:

1. منع الخروج عن النطاق:
   تثبيت currentPage بين 1 و totalPages.

2. تعطيل الأزرار غير الصالحة:
   تعطيل زر Prev عند الصفحة 1، وتعطيل زر Next عند totalPages.

3. تغيير عدد الصفوف:
   عند تغيير pageSize نرجّع currentPage = 1 فوراً.

4. حالة صفر مستخدمين:
   نضمن إن totalPages يكون 1 على الأقل.
